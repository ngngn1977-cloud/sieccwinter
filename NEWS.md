# sieccwinter 1.0.0

- First public release (sealed 15 October 2026). Source fingerprint
  349C146ADC1B39E14CBB7024BAC6917F64FBDF1BA9F6294DE7A92209F361125D.
- Implements the SIECC Winter workflow: core validation, Batches A-C, the
  refined ordinal models, the distributed-lag validations, cold burden, the
  daily layer, anomaly history, the coded model record and the exposure export.
- Implements the post hoc protocol v2 (steps 18-30): deletion, L59 bootstrap,
  no-April, source agreement, exposure residuals, profile likelihood,
  early/late, H3 nested test, nearest station, exposure QA, VIF summary,
  calendar spline and age 65.
- Contains no study data. A fully synthetic data set is provided for workflow
  demonstration only; the private validation material is held locally.
- Validated on R 4.4.3; requires R (>= 4.4.0).
- Author, maintainer, licence-holder, citation and repository metadata
  completed. Released under the MIT licence. DOI to be added after the Zenodo
  release.
